      How the score and the scan work

      The same logic the Python implementation and its evaluation harness use.

      Comment and string masking

      Comments, docstrings and string literals are blanked before matching, with newlines preserved so line numbers stay exact. An algorithm named only in prose is documentation, not a call site, and is reported separately instead of counted.

      Per-line deduplication

      A single call site often matches several patterns — hashlib.sha256( matches both the qualified and the bare form. Matches collapse per line and family, keeping the most specific, so one call site is one finding.

      Exposure score

      Severity alone saturates: any file with four high findings pins at 100. The score instead combines worst severity (≤60), distinct families (≤20) and findings per hundred lines with diminishing returns (≤20).

      Known limits

      Detection is lexical. It finds cryptographic API usage, not misuse of a correctly-named primitive, and does not follow indirection through wrappers. Treat output as a migration worklist, not an audit.
